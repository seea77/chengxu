# 计分大屏（班级平时成绩展示）

一个**可双击运行的便携计分大屏**程序，用于课堂平时成绩实时展示与排名。
基于网页（HTML/CSS/JS）封装为原生窗口（pywebview + PyInstaller），数据以侧车文件 `date.json` 形式随程序拷贝，无需数据库、无需导入导出。

## 两个版本

| 版本 | 文件名 | 称号（示例） |
|------|--------|--------------|
| 通用版 | `计分大屏.exe` | 榜首之星 / 传奇学霸 / 金牌学员 … |
| 摄影版 | `摄影计分大屏.exe` | 摄影之星 / 传奇掌镜 / 金牌摄影师 … |

> 程序按 exe 文件名自动选择页面：文件名含「摄影」加载摄影版，否则加载通用版。

## 功能

- 班级 / 学生管理，按周录入平时分（绿格标记已录）
- 前 10 名放大展示、其余横向滚动；荣誉称号随分数自动评定
- 随机选人（课堂互动），可等比适配大屏
- **批量加分**：勾选多名学生 → 统一对指定周次加/减分
- 左上角图标可自定义（emoji / 文字 / 本地图片），随数据保存
- 启动检测 Edge WebView2 运行时，缺失时弹窗提示并引导官方下载

## 运行（开发模式）

```bash
pip install -r requirements.txt
python main.py
```

## 打包为 exe

```bash
pyinstaller 计分大屏.spec --noconfirm        # 通用版
pyinstaller 摄影计分大屏.spec --noconfirm     # 摄影版
```

产物位于 `dist/`，图标来自 `app.ico`。

## 给最终用户

- 需要目标电脑已安装 **Microsoft Edge WebView2 运行时**（Win10/11 大多自带；缺失会自动提示并给下载链接）。
- 分发时把 `exe` 与同目录的 `date.json` 一起拷贝即可，拷到别的电脑数据照常显示。

## 目录说明

| 文件 | 作用 |
|------|------|
| `main.py` | 启动器：本地 HTTP 服务 + pywebview 窗口 + WebView2 检测 + 数据注入/落盘 |
| `index.html` | 通用版页面 |
| `index_photo.html` | 摄影版页面 |
| `*.spec` | PyInstaller 打包配置 |
| `app.ico` | exe 图标 |
| `date.json` | **用户数据（不入库）** |
